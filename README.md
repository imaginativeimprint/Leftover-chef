# Leftover-Chef 🍳

Leftover-Chef is a lightweight, responsive web application designed to help minimize food waste and maximize kitchen efficiency. It allows users to select the ingredients they currently have on hand and instantly suggests customized, practical recipes they can make right away.

---

## Features
* **Ingredient-Based Filtering:** Select from a variety of available household or leftover ingredients.
* **Instant Recipe Suggestions:** Dynamically generates matching meal ideas based on your selections.
* **Minimalist & Responsive UI:** Built with clean HTML and JavaScript for a fast, seamless experience across desktop and mobile devices.

---

## Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** Python , Flask
* **Database:** PHPMYADMIN
